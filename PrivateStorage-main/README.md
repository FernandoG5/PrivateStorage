# PrivateStorage

Repositorio oficial del proyecto **PrivateStorage**, una aplicación web orientada al control de inventariado y puntos de venta.

---

## Objetivo General del Proyecto

Desarrollar una aplicación web cuyo objetivo es ofrecer herramientas de punto de venta y manejo de inventario, que además, permita la administración remota de diferentes sucursales y registro de ventas de las mismas.

## Objetivos Específicos del Proyecto

Desarrollo de una aplicación web dedicada al comercio de productos electrónicos y hardware/dispositivos para computación, inventariado multi-sede, manejo de inventario en tiempo real, datos de ventas por sucursal y globales, manejo y gestión de usuarios/empleados y gestión de sucursales.
