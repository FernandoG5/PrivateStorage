# PrivateStorage

Repositorio oficial del proyecto **PrivateStorage**, una aplicación web orientada al control de inventariado y puntos de venta.

---

## Objetivo General del Proyecto

Desarrollo de una aplicación web dedicada al punto de venta e inventariado multi-sede que permita la administración centralizada de diferentes sucursales, control de inventario actualizado de productos y registro de ventas.
